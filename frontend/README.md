# frontend

React + TypeScript + Vite, with Redux Toolkit (from MEDGENT-016 onward).

See the root [`README.md`](../README.md) for how to run this alongside the
backend, and `../steering/02-code-quality.md` for lint/type-check
standards.

```bash
npm install
npm run dev      # start dev server
npm run lint     # eslint
npm run format   # prettier --write
```
